Simulator Control

Write your UI logic in app.js. The simulator provides a tft object with Adafruit_GFX-like methods.

Joy L (X,Y): 2048, 2048
Joy R (X,Y): 2048, 2048
Active Buttons: None

Available Methods

  • tft.fillScreen(color)
  • tft.drawRect(x,y,w,h,color)
  • tft.fillRect(x,y,w,h,color)
  • tft.drawCircle(x,y,r,color)
  • tft.fillCircle(x,y,r,color)
  • tft.drawLine(x0,y0,x1,y1,color)
  • tft.setTextColor(color, bg)
  • tft.setTextSize(size)
  • tft.setCursor(x, y)
  • tft.print(text)

Colors use 16-bit RGB565 format (e.g., 0xF800 for Red), or standard CSS strings.
